# Vervue — AI Usage Log

Vervue was developed using an iterative AI-assisted / vibe-coding workflow.

AI was used throughout the project for:
- Initial project planning and architecture
- Deciding the interview flow and candidate experience
- Designing candidate-specific and adaptive interview questions
- Prompt refinement and interview-question quality
- Backend and API implementation guidance
- React + Vite frontend development
- UI/UX iteration and light/dark theme design
- Debugging and testing
- Transcript and feedback functionality
- Production deployment and API configuration
- Final testing and deployment troubleshooting

The development process was not a single AI-generated implementation. Features were discussed, implemented, tested locally, reviewed based on actual behaviour, and iteratively refined.
